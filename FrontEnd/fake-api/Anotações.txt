JSON SERVER

Facilita o desenvolvimento Front-End, pra vc não ter que esperar
 o programador Back-End desenvolver a API
 criar uma API Falsa (API Rest)
 db.json


Como Instalar

Abrir o terminal, poder ser do VS code ou não e rodar o seguinte comando:
 npm install-g json server
   (com a flag/parâmetro) -g vc instala o json-server de forma global,
 para qualquer projeto que vc precisa usar depois
   criar o arquivo  db.json na raiz do seu projeto (no Vscode) - Este arquivo serve como 
banco de dados do json server e ele mesmo controla esse arquivo cada requisoção


Exemplo de Estrutura:

  {
     "Rota/EndPoint":[
      {"id":1,"dado-qualquer":"valor qualquer"}
    ]
  }


Exemplo Fictício:
{
   "usuario":[
       {"id":1,"nome":"Paulo Andre",:"email":"pa@gmail.com","idade":17}
       {"id":2,"nome":"Davi Muniz",:"email":"davi@gmail.com","idade":17}   
  ]
}

No VSCode devemos abrir o terminal e alterar para o terminal do git bash (testar o do
 windows?)
Rodar o comando json-server --watch db.json
